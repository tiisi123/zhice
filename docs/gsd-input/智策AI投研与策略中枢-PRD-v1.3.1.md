## 1. 问题陈述

### 1.1 背景

当前金融数据市场存在**显著的产品缺口**：现有工具主要提供通用行情数据，**缺乏从投资策略视角出发的深度复盘能力**，更没有将 AI 生成与回测融入日常工作流的解决方案。同时，投资者跨资产类别（股票、ETF、期货、债券）的配置需求日益增长，但现有工具各资产类别割裂，无法一站式覆盖。

### 1.2 核心痛点

| 痛点 | 现状 | 成本 |
|------|------|------|
| 复盘效率低 | 每日需 2-3 小时手动整理行情数据 | 时间浪费，错过盘中机会 |
| 数据碎片化 | 板块轮动、题材热点、产业链、期货基差、债券利差分散在多数据源 | 分析不系统 |
| 策略验证困难 | 有想法却无法快速回测验证 | 好想法无法落地 |
| 缺乏 AI 辅助 | 竞品仅有基础数据展示 | 无法复制优秀投资者的思维框架 |
| 跨资产割裂 | 股票/ETF/期货/债券分散在不同工具 | 配置效率低 |
| 信息过载 | 海量行情/公告/研报，关键信息淹没 | 错过重要信号 |

### 1.3 市场空白

- **现有产品**：通用行情数据 + 基础图表，资产类别割裂
- **用户需要**：策略驱动复盘 + AI 生成回测 + 多资产覆盖 + 不同风格适配
- **市场缺口**：暂无竞品同时满足"多资产策略风格适配 + AI 全流程覆盖 + 持仓风控一体化"

## 2. 目标与非目标

### 2.1 产品目标

| 目标 | 衡量指标 | 目标值 |
|------|----------|--------|
| 建立活跃用户基础 | 每周使用产品复盘人数 | ≥ 500 人 |
| 实现付费转化 | 每周使用 VIP 功能人数 | ≥ 100 人 |
| 提升复盘效率 | 用户平均复盘时间减少 | ≥ 50% |
| 建立 AI 差异化 | 行业首个覆盖股票/ETF/期货/债券的策略风格 AI 复盘平台 | 领先竞品 |

### 2.2 资产类别覆盖范围

| 资产类别 | v1.3.1 | 覆盖深度 | 策略风格数 |
|----------|--------|----------|-----------|
| **股票** | ✓ 完整 | 4 种策略风格，完整复盘+回测+AI | 4 |
| **ETF** | ✓ 完整 | 1 种策略风格（轮动），含行情复盘看板+信号跟踪+组合池+交易执行信号三大模块 | 1 |
| **期货** | ✓ 基础 | 3 种策略风格（趋势跟踪/套利/日内），复盘+基差分析+回测 | 3 |
| **债券** | ✓ 基础 | 2 种策略风格（利率/信用），复盘+收益率曲线+久期管理 | 2 |

### 2.3 非目标（Out of Scope）

| 排除项 | 原因 |
|--------|------|
| 实盘交易下单 | 合规风险 |
| 资讯内容生产 | 版权风险，专注数据与工具层 |
| 用户讨论区 | 运营成本高，MVP 非必需 |
| 移动端原生 App | 聚焦 PC Web 体验 |
| 港股/美股/海外期货 | 当前专注境内市场 |
| FOF 资产 | 独立为另一系统（见 v1.3.2） |
| 第三方 Agent 市场 | P2 远期规划 |

**ETF 四层筛选漏斗**：

```

    │

    │   - 规模 > 2 亿
```
