## 1. 核对范围与基准

### 1.1 核对基准

- **PRD版本**：v1.3.1（`智策AI投研与策略中枢-PRD-v1.3.1.md`）
- **DEMO地址**：`http://121.199.79.169:3001/replay`
- **核对范围**：股票资产模块（PRD §3.1-3.4 用户故事 + §4.2 需求规格 + §4.1 共通平台服务）
- **排除范围**：ETF资产、期货资产、债券资产（DEMO未覆盖，不在此次核对范围）

### 1.2 核对方法论

| 标记 | 含义 |
|------|------|
| ✅ 已覆盖 | DEMO中已有对应实现，功能与验收标准基本匹配 |
| ⚠️ 部分覆盖 | DEMO中有对应功能但存在缺口（数据不完整/交互简化/验收标准未全部满足） |
| ❌ 未覆盖 | DEMO中无对应实现 |
| 🔧 需修改 | DEMO中有实现但与PRD规格描述不一致，需调整 |

### 2.3 DEMO设计风格特征

| 特征 | 描述 |
|------|------|
| 布局 | 侧边导航（Sider）+ 顶部栏（Header）+ 内容区（Content），Ant Design Layout |
| 色系 | 蓝色主色调（#1677ff），情绪五色（冰点蓝/低迷青/中性灰/回暖橙/高潮红） |
| 卡片 | 左侧彩色Border强调（4px），渐变背景卡片（叙事头/作战流），阴影层次 |
| 数据展示 | 数值用大字体+粗体，涨红跌绿，Tag标记状态，Badge排序号 |
| AI标识 | AIBadge组件统一标记AI生成内容，AIDisclaimer风险提示 |
| 交互 | 气泡图点击下钻，Tabs切换视角，日期选择器，搜索框，实时轮询（6秒） |
| 叙事设计 | "三幕叙事"（Act 1/2/3）、"五步作战流"（情绪→主线→龙头→风险→次日） |
