## 1. 全局设计系统

### 1.1 设计原则

| 原则 | 说明 | 设计体现 |
|------|------|----------|
| **策略视角** | 以投资策略为组织单元，非数据堆砌 | 每种策略风格独立工作台，导航按风格分区 |
| **叙事驱动** | 数据讲述故事，降低认知负荷 | 三幕叙事头、五步作战流延续到ETF模块 |
| **层层下钻** | 总览→分类→明细→个股/单ETF | 每层都有全景视图和明细入口 |
| **AI无处不在** | AI不是功能，是贯穿全流程的层 | 每个模块都有AI摘要/AI问询入口 |
| **实时可感** | 数据刷新状态可视化 | DataStatusBadge + 实时计数器 + 更新时间 |

### 1.5 通用组件规范

#### 卡片 (Card)

```
┌─ 4px彩色左边框（可选，用于强调）──────────┐
│ 📌 卡片标题                    [操作按钮] │
│                                           │
│  核心数据 (32px 粗体)                      │
│  辅助描述 (12px #999)                      │
│                                           │
│  ├─ 图表区域                               │
│  └─ 底部统计/标签                          │
└───────────────────────────────────────────┘

变体：
- default: 白色背景，1px #f0f0f0 边框，borderRadius: 8
- emphasized: 左侧4px彩色Border + 浅色渐变背景
- narrative: 渐变背景（如 #fff7e6→#fff），故事化叙事
- data-highlight: 居中大数字，无边框，纯数据展示
```

#### SectionHeader

```tsx
<SectionHeader
  icon={<FireOutlined />}
  title="题材热度排行"
  subtitle="综合涨停数+成交额+新闻量"
  extra={<AskAIChip prompt="分析当前题材轮动" />}
  meta={<DataStatusBadge status="live" source="Wind" />}
/>
```

#### AIBadge / AIDisclaimer

```
┌─ AIBadge ─────────────────┐
│ 🤖 AI 生成 · 仅供参考      │
└───────────────────────────┘

每个AI生成内容区块底部统一放置 AIDisclaimer：
"以上内容由AI自动生成，不构成投资建议。请结合自身判断使用。"
```
