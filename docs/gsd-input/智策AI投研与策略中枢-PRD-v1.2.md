## 1. 问题陈述

### 1.1 背景

当前金融数据市场存在**显著的产品缺口**：现有工具主要提供通用行情数据，**缺乏从投资策略视角出发的深度复盘能力**，更没有将 AI 生成与回测融入日常工作流的解决方案。

### 1.2 核心痛点

| 痛点 | 现状 | 成本 |
|------|------|------|
| 复盘效率低 | 每日需 2-3 小时手动整理行情数据 | 时间浪费，错过盘中机会 |
| 数据碎片化 | 板块轮动、题材热点、产业链分散在多数据源 | 分析不系统，决策盲区 |
| 策略验证困难 | 有想法却无法快速回测验证 | 好想法无法落地 |
| 缺乏 AI 辅助 | 竞品仅有基础数据展示 | 无法复制优秀投资者的思维框架 |
| 持仓管理割裂 | 复盘工具与持仓管理分离，需多平台切换 | 决策与执行脱节 |
| 信息过载 | 海量行情/公告/研报，关键信息淹没 | 错过重要信号 |

### 1.3 市场空白

- **现有产品**：通用行情数据 + 基础图表
- **用户需要**：策略驱动复盘 + AI 生成回测 + 不同风格适配 + 一站式投研工作流
- **市场缺口**：暂无竞品同时满足"策略风格适配 + AI 全流程覆盖 + 持仓风控一体化"

## 2. 目标与非目标

### 2.1 产品目标

| 目标 | 衡量指标 | 目标值 |
|------|----------|--------|
| 建立活跃用户基础 | 每周使用产品复盘人数 | ≥ 500 人 |
| 实现付费转化 | 每周使用 VIP 功能人数 | ≥ 100 人 |
| 提升复盘效率 | 用户平均复盘时间减少 | ≥ 50% |
| 建立 AI 差异化 | 行业首个按投资风格定制的 AI 复盘平台 | 领先竞品 |
| 用户激活率 | 注册后 7 日内完成首次复盘的比率 | ≥ 70% |

### 2.2 非目标（Out of Scope）

| 排除项 | 原因 |
|--------|------|
| 实盘交易下单 | 合规风险，与券商系统协作 |
| 资讯内容生产 | 版权风险，专注数据与工具层 |
| 通用金融搜索 | 已有成熟竞品，聚焦差异化 |
| KYC 认证 | MVP 阶段仅需手机号注册 |
| 用户讨论区 | 运营成本高，MVP 非必需 |
| 移动端原生 App | 聚焦 PC Web 体验，适配移动端浏览器 |
| 港股/美股 | MVP 专注 A 股核心场景 |
| 第三方 Agent 市场 | P2 远期规划 |

### 4.4 模块四：AI-Agent协同与交互中枢（按投资风格）

> **设计理念**：不同投资风格的投资经理，复盘时关注的信息、使用的工具、分析的逻辑完全不同。智策的 AI Agent 需要**理解用户的投资风格**，提供**定制化的复盘流程和数据呈现**。

---

#### 4.4.1 投资风格定义与特征

| 风格 | 核心逻辑 | 关注数据 | 典型指标 |
|------|----------|----------|----------|
| **打板/强势股** | 追涨杀跌，跟随主力 | 涨停、封单、情绪 | 连板次数、封单强度、溢价率 |
| **主题/热点轮动** | 题材驱动，产业链传导 | 消息、题材、产业链 | 热度值、传导时滞、关联度 |
| **成长/景气度** | 行业景气，业绩增长 | 宏观、中观、行业 | PMI、景气度指数、增速 |
| **价值/基本面** | 估值合理，业绩稳健 | 财报、研报、另类 | PE、PB、ROE、预期差 |
| **ETF轮动** | 指数化配置，板块轮动 | ETF资金流、折溢价、份额 | 资金净流入、折溢价率、动量 | **[v1.2新增]**
