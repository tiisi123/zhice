# 成长/价值产品改造方案

> 生成日期：2026-04-26  
> 范围：成长/价值大板块、PRD 成长/景气度与价值/基本面模块、现有 Web 页面、A 股中长线投资经理工作流。  
> 目标：将当前分散的成长/价值功能改造成面向专业用户的中长线投研决策工作台。

---

## 1. 访谈结论

本轮访谈确认以下方向：

| 问题 | 结论 |
|---|---|
| 目标用户 | 有持仓 + 找机会的专业用户 |
| 业务覆盖 | 公募/私募投资经理、研究员、中长线个人投资者、投顾/组合管理者都要兼容 |
| 首页定位 | 三者都有，但首页先给总览：行业配置、个股研究、持仓管理 |
| 最强付费点 | 景气度拐点预警、AI 财报解读、估值合理区间、持仓诊断、调仓建议、行业/公司深度报告生成，全部都是付费点 |
| 主入口设计 | 拆成“成长景气”和“价值基本面”两个主入口，并新增“成长/价值总览” |
| 行业体系 | 申万一级/二级 + 概念/题材 + ETF 映射行业 |
| 个股入口 | 默认案例 + 用户输入 |
| 动作表达 | 可使用“AI 参考建议：加仓 / 持有 / 减仓 / 剔除 / 观察”，同时明确仅供研究参考 |
| AI 输出风格 | 建议采用“投委会决策备忘录” |

---

## 2. 产品定位

成长/价值板块不应只是财报、估值、景气度、ETF、研报等工具的集合，而应成为专业用户的中长线投研决策工作台。

核心目标：

```text
帮助用户判断当前 A 股中长线该配什么、避开什么、持仓怎么调、机会从哪里找。
```

产品要同时回答两类问题：

```text
1. 我现在持仓有没有风险？
2. 市场现在还有哪些中长线机会？
```

因此，成长/价值模块的主线应从“看数据”升级为“形成配置建议”。

---

## 3. 核心分析框架

面向 A 股中长线投资，建议固定采用五层分析框架：

```text
宏观环境 -> 行业景气 -> 公司质量 -> 估值与预期差 -> 组合动作
```

### 3.1 宏观环境

判断市场是否支持成长或价值风格。

核心指标：

- PMI / PPI / CPI
- 社融 / M2
- 利率 / 汇率
- 政策方向
- 市场风险偏好
- 流动性边际变化

产品输出：

```text
当前宏观环境是否支持成长股估值扩张？
是否更适合红利、低估值、防御资产？
```

### 3.2 行业景气

判断哪些行业未来 3-12 个月基本面向上。

核心指标：

- 行业景气度分数
- 环比/同比变化
- 库存周期
- 价格变化
- 订单变化
- 产能利用率
- 中观数据
- 产业链上下游传导

产品输出：

```text
哪些行业景气上行？
哪些行业出现拐点？
哪些行业只是反弹，尚未确认趋势？
```

### 3.3 公司质量

判断公司是否真正受益于行业景气。

核心指标：

- 营收增长
- 净利润增长
- ROE
- 毛利率
- 现金流
- 负债率
- 资本开支
- 市占率
- 护城河
- 管理层质量

产品输出：

```text
公司是行业真龙头，还是短期受益？
基本面质量是否支撑长期持有？
```

### 3.4 估值与预期差

判断当前价格是否已经反映基本面。

核心指标：

- PE / PB / PS / EV/EBITDA
- 历史估值分位
- DCF 合理区间
- 卖方一致预期
- EPS 上修/下修
- 目标价变化
- 业绩预告与市场预期差
- 另类数据验证

产品输出：

```text
当前价格贵不贵？
盈利上修是否足以覆盖估值扩张？
市场是否低估了行业或公司变化？
```

### 3.5 组合动作

将研究结论转化为可执行的参考动作。

建议动作词：

```text
AI 参考建议：加仓 / 持有 / 减仓 / 剔除 / 观察
```

每个动作必须包含：

- 理由
- 触发条件
- 失效条件
- 跟踪指标
- 风险提示

示例：

```text
AI 参考建议：观察
理由：行业景气改善已确认，但估值分位处于 78%，盈利上修尚未覆盖估值扩张。
触发条件：下季度订单继续改善，或估值回落至 60% 分位以下。
失效条件：毛利率继续下滑，卖方一致预期下修。
```

```text

```

### 4.1 模块映射

| 原模块 | 新位置 | 改造方向 |
|---|---|---|

## 5. 成长/价值总览

### 5.1 页面目标

让用户 3 分钟知道：

```text
当前 A 股中长线风格是什么？
我的持仓有没有风险？
市场还有哪些行业和公司机会？
组合应该如何调整？
```

### 5.2 首屏结构

建议首屏结构：

```text
顶部：中长线配置结论
左侧：持仓健康度
中间：市场机会地图
右侧：AI 投委会备忘录
下方：景气、估值、预期、ETF 证据区
```

### 5.3 首屏内容

顶部结论条：

```text
当前风格：成长修复 / 价值防御 / 均衡配置
景气方向：半导体、创新药、AI 算力
价值方向：红利、银行、白酒、资源
估值状态：成长估值修复至中位，红利拥挤度升高
预期差：新能源车盈利预期下修，半导体设备预期上修
组合动作：成长加到中性偏高，红利从超配降到标配
```

### 5.4 推荐图示

- 成长/价值风格跷跷板
- 行业景气机会地图
- 持仓健康度仪表盘
- 估值分位散点图
- 预期修正时间线
- ETF 映射确认图

### 5.5 页面原则

首页不堆大表格。

首页只做“决策总览”，明细进入成长景气或价值基本面。

## 6. 成长景气

### 6.1 页面目标

找到未来 3-12 个月景气向上的行业和高弹性方向。

### 6.2 分析主线

```text
宏观流动性 -> 行业景气 -> 产业链传导 -> ETF确认 -> 成长候选池
```

### 6.3 子板块

| 子板块 | 核心问题 | 展示方式 |
|---|---|---|
| 景气总览 | 哪些行业景气最强？ | 行业景气热力图 |
| 拐点预警 | 哪些行业刚刚转好？ | 拐点雷达 / 变化榜 |
| 扩散指数 | 景气是局部还是全面扩散？ | 扩散仪表盘 |
| 产业链传导 | 上中下游谁先受益？ | 产业链传导图 |
| ETF 映射 | 资金是否确认行业方向？ | ETF 轮动四象限 |
| 成长候选池 | 哪些公司弹性最大？ | 候选卡片 + 明细 |

### 6.4 页面信息流

```text
[今日成长结论]
流动性是否支持成长？
哪些行业景气上行？
拐点在哪里？
上中下游谁最受益？
ETF/行业指数是否确认？
哪些公司值得进入观察池？
```

### 6.5 图示优先级

优先做：

- 申万一级/二级行业景气热力图
- 概念/题材景气趋势图
- 行业生命周期曲线
- 景气扩散指数
- 拐点雷达
- 产业链上中下游传导图
- ETF 轮动四象限

表格只用于展开明细。

### 6.6 AI 输出

AI 应输出成长配置备忘录：

```text
一、成长风格结论
二、景气上行行业
三、拐点行业
四、ETF/资金确认
五、候选公司
六、反向风险
七、AI参考建议：加仓 / 持有 / 减仓 / 剔除 / 观察
```

## 7. 价值基本面

### 7.1 页面目标

判断公司质量、估值安全边际和预期差，辅助组合调整。

### 7.2 分析主线

```text
持仓诊断 -> 公司质量 -> 财报变化 -> 估值位置 -> 预期差 -> AI参考动作
```

### 7.3 子板块

| 子板块 | 核心问题 | 展示方式 |
|---|---|---|
| 持仓诊断 | 当前组合有没有高估、恶化、集中风险？ | 持仓健康度 + 暴露图 |
| 个股画像 | 公司质量是否优秀？ | 公司质量雷达 |
| 财报追踪 | 基本面有没有变化？ | 财报趋势图 / 异常提示 |
| 估值分析 | 当前价格贵不贵？ | 历史估值分位带 / DCF |
| 多公司对比 | 同行业谁更优？ | 质量雷达 + 维度排序 |
| 预期差跟踪 | 卖方预期是否上修或下修？ | 预期修正时间线 |
| 公告/研报/另类数据 | 是否有新证据？ | 事件流 + 信号标签 |

### 7.4 页面信息流

```text
[今日价值结论]
组合估值贵不贵？
持仓质量有没有恶化？
财报有没有异常科目？
卖方预期是上修还是下修？
当前价格是否有安全边际？
该加仓、持有、减仓、剔除还是观察？
```

### 7.5 图示优先级

优先做：

- 公司质量雷达图
- 财报趋势图
- 财报异常瀑布图
- PE/PB 历史分位带
- DCF 敏感性矩阵
- 卖方预期修正时间线
- 组合行业/风格暴露图

表格只放在“更多明细”里。

### 7.6 AI 输出

AI 应输出价值基本面备忘录：

```text
一、公司/组合核心结论
二、基本面质量
三、财报变化
四、估值与安全边际
五、预期差
六、反向风险
七、跟踪指标
八、AI参考建议：加仓 / 持有 / 减仓 / 剔除 / 观察
```

## 9. UI / UE 原则

### 9.1 结论先行

每个页面顶部必须先回答：

```text
现在怎么看？
为什么？
下一步做什么？
```

不允许一进入页面就是大表格。

### 9.2 图示优先

成长/价值模块要减少表格堆砌，优先使用：

- 热力图
- 雷达图
- 分位带
- 敏感性矩阵
- 时间线
- 传导图
- 四象限
- 组合暴露图

### 9.3 表格下沉

表格保留，但作为：

- 明细展开
- 数据校验
- 可导出材料
- 专业用户二次筛选

### 9.4 动作闭环

每页底部应落到：

```text
AI参考建议
跟踪指标
触发条件
失效条件
风险提示
```

### 9.5 A 股专业风格

建议采用：

```text
70% 专业机构工作台
20% 研究报告式结论表达
10% 投资仪表盘视觉强化
```

页面应克制、高密度、结论明确，不做营销式大卡片和装饰型图形。

## 10. AI 投委会决策备忘录模板

AI 输出建议统一为“投委会决策备忘录”。

模板：

```text
# 投委会决策备忘录

## 一、核心结论
用 1-3 句话说明当前判断。

## 二、配置逻辑
说明宏观、景气、公司、估值、预期差之间的逻辑链。

## 三、关键证据
列出 3-5 个最重要证据。

## 四、反向风险
列出可能推翻结论的风险。

## 五、跟踪指标
列出后续需要持续观察的数据。

## 六、AI参考建议
加仓 / 持有 / 减仓 / 剔除 / 观察

## 七、触发条件与失效条件
明确什么情况下动作升级，什么情况下结论失效。

## 八、免责声明
以上内容仅供研究参考，不构成任何投资建议。
```

## 12. 分阶段改造计划

### Phase 1：导航与总览页

目标：建立成长/价值的统一入口和专业第一印象。

任务：

- 将成长/价值一级菜单收敛为：成长/价值总览、成长景气、价值基本面
- 新增成长/价值总览页
- 总览页展示持仓风险 + 市场机会
- 接入 AI 投委会备忘录入口

### Phase 2：成长景气整合

目标：把景气度分析、景气度中心、ETF 轮动整合成行业配置链。

任务：

- 景气热力图升级
- 拐点预警图示化
- 产业链传导图示化
- ETF 映射确认
- 成长候选池

### Phase 3：价值基本面整合

目标：把持仓、财报、估值、对比、研报整合成公司研究链。

任务：

- 持仓健康度
- 公司质量雷达
- 财报趋势与异常
- 估值分位带
- DCF 敏感性矩阵
- 卖方预期修正时间线
- AI 参考动作

### Phase 4：数据沉淀与个性化

目标：从静态示例走向专业用户可持续使用。

任务：

- 行业体系映射表
- ETF 映射表
- 用户研究池与持仓联动
- 报告归档
- 预警规则
- 个性化投研备忘录

## 13. 第一刀建议

推荐第一刀：

```text
导航结构 + 成长/价值总览页
```

原因：

- 用户第一眼能感知产品变专业
- 不破坏现有功能，只是重新组织
- 后续成长景气、价值基本面都能自然承接
- 最符合“有持仓 + 找机会”的用户场景

第一版总览页不追求数据全部真实完备，重点是把信息流和决策结构搭起来。

## 14. 页面内横向子模块导航

### 14.1 设计原则

成长/价值板块建议采用：

```text
左侧一级导航：成长/价值总览、成长景气、价值基本面
页面内横向导航：当前页面内的研究步骤
```

横向导航要体现中长线投资经理的研究路径：

```text
配置结论 -> 证据验证 -> 标的筛选 -> 风险评估 -> 组合动作
```

统一原则：

- 每个页面默认打开“结论型 Tab”，而不是数据明细。
- 横向导航按投研流程排序，不按数据来源排序。
- 图示优先，表格下沉。
- 重要风险或机会可在 Tab 上显示数量徽标。
- 用户输入的行业、股票、日期区间在 Tab 切换时保持不变。
- AI 投委会备忘录作为页面右侧或底部固定能力，贯穿所有 Tab。

### 14.2 成长/价值总览横向导航

页面目标：同时回答“持仓有没有风险”和“市场还有哪些中长线机会”。

横向导航：

```text
配置结论 | 持仓健康 | 机会地图 | 估值分位 | 预期修正 | ETF确认
```

| Tab | 核心问题 | 推荐展示 |
|---|---|---|
| 配置结论 | 当前该偏成长、价值还是均衡？ | 中长线结论条、风格跷跷板、AI 参考动作 |
| 持仓健康 | 我的组合有没有风险？ | 持仓风险灯、行业暴露、估值偏高名单 |
| 机会地图 | 市场机会在哪里？ | 行业景气热力图、成长/价值机会卡 |
| 估值分位 | 便宜还是贵？ | 行业/个股估值散点、历史分位带 |
| 预期修正 | 谁在上修或下修？ | 卖方预期时间线、EPS 变化 |
| ETF确认 | 资金是否确认方向？ | ETF 映射行业、轮动四象限 |

专业建议：总览页默认打开“配置结论”，但首屏要露出“持仓健康”和“机会地图”的摘要，服务“有持仓 + 找机会”的用户。

### 14.3 成长景气横向导航

页面目标：找到未来 3-12 个月景气向上的行业和公司。

横向导航：

```text
宏观灯塔 | 景气热力 | 拐点预警 | 产业链传导 | ETF映射 | 成长候选
```

| Tab | 核心问题 | 推荐展示 |
|---|---|---|
| 宏观灯塔 | 宏观和流动性是否支持成长？ | PMI/社融/利率方向、风险偏好灯 |
| 景气热力 | 哪些行业景气最强？ | 申万一级/二级热力图、概念趋势 |
| 拐点预警 | 哪些行业刚转好？ | 拐点雷达、环比变化、扩散指数 |
| 产业链传导 | 上中下游谁最受益？ | 传导图、利润分配、时滞 |
| ETF映射 | 资金是否正在流入？ | ETF 轮动四象限、成交额、份额变化 |
| 成长候选 | 哪些公司弹性最大？ | 候选池卡片、景气弹性、估值约束 |

专业建议：“宏观灯塔”只给投资含义，不堆宏观表。成长景气最重要的是拐点和弹性，默认可打开“景气热力”，顶部保留宏观结论摘要。

### 14.4 价值基本面横向导航

页面目标：判断公司质量、估值安全边际和预期差。

横向导航：

```text
持仓诊断 | 个股画像 | 财报追踪 | 估值分析 | 公司对比 | 预期差 | 研究证据
```

| Tab | 核心问题 | 推荐展示 |
|---|---|---|
| 持仓诊断 | 当前组合该怎么调？ | 组合健康度、风险集中、AI 参考动作 |
| 个股画像 | 公司质量如何？ | 质量雷达、护城河、财务健康评分 |
| 财报追踪 | 基本面是否变化？ | 营收/净利趋势、异常科目、现金流 |
| 估值分析 | 当前价格是否合理？ | PE/PB 分位带、DCF 敏感性矩阵 |
| 公司对比 | 同行业谁更优？ | 多公司雷达、质量/成长/估值排序 |
| 预期差 | 市场预期是否充分？ | 预期修正时间线、目标价/EPS 变化 |
| 研究证据 | 新公告、研报、另类数据支持吗？ | 事件流、信号标签、AI 摘要 |

专业建议：价值基本面默认打开“持仓诊断”或“个股画像”，取决于是否有持仓数据；若无持仓，默认打开“个股画像 + 默认案例”。

### 14.5 横向导航与 AI 联动

成长/价值板块的 AI 输出建议始终使用“投委会决策备忘录”，并根据当前 Tab 自动切换重点：

```text
配置结论 Tab：输出资产/风格配置建议
景气热力 Tab：输出行业配置备忘录
估值分析 Tab：输出估值合理性判断
预期差 Tab：输出上修/下修风险
持仓诊断 Tab：输出组合调仓参考
```

专业建议：横向导航不是视觉装饰，它应该驱动 AI 上下文，让 AI 知道用户当前是在做哪一步研究。
