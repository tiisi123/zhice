# 成长价值接口映射清单

> 生成日期：2026-04-27  
> Owner：Growth Value / 成长价值  
> 范围：成长/价值总览、成长景气、价值基本面、财报、估值、ETF、研究中心相关页面与 `/api/growth/*`、`/api/value/*`、`/api/finance/*`、`/api/etf/*`、`/api/research/*`。  
> 说明：本清单基于当前代码静态梳理，不新增数据源，不删除 mock/示例数据；状态中的“真实优先”表示代码会尝试真实源，失败后可能回退到示例或静态数据。2026-04-27 已对成长价值相关 route 做最小契约补齐，顶层返回 `source/data_status/mock/message`，业务算法未改。

## 8. 契约缺口与最小改造建议

1. 成长价值相关 route 已统一补顶层 `source/data_status/mock/message`。当前仍保留原有 `data_source`、`data_mode`、`data_flag` 等字段以兼容前端。
2. 本轮只做契约补齐，不改算法：
   - 真实源正常：`source=dfcf/tushare/tushare_fund_daily`、`data_status=ok`、`mock=false`。
   - 真实源部分可用：`data_status=partial`，逐行保留 `data_flag`。
   - sample/mock 回退：`source=sample_engine/static_sample`、`data_status=stale` 或 `empty`，`mock` 为真实布尔状态。
   - 规则推演：在 `message` 中说明，避免和真实原始数据混淆。
3. 优先收敛重复口径：
   - 公告：以 `/finance/announcements/{code}` 真实源为主，`/research/announcements` 标记为全市场公告 mock 或迁移。
   - 研报/卖方预期：收敛 `/finance/research-reports`、`/value/expectations`、`/value/expectation-history`、`/research/sellside`。
   - 持仓：`/growth/portfolio` 接用户持仓/研究池前必须显式 mock。
4. 前端建议统一展示数据状态：
   - Growth/Value 页面顶部展示数据源标签。
   - 当 `mock=true` 或 `data_status=stale` 时显示 `MockBanner` 或状态提示。
   - AI 输出旁展示“基础数据：真实/样例/规则推演”。
