# 数据源治理规范

## 默认数据源

| 数据 | 主源 | 说明 |
| --- | --- | --- |
| 涨停池 | KPL | 盘中短线核心数据 |
| 炸板池 | KPL | 盘中短线核心数据 |
| 热股榜 | KPL | 人气与行情合成 |
| 市场异动 | KPL | 盘中异动 |
| 龙虎榜 | KPL | 游资席位和个股列表 |
| 日 K | Tushare | 历史行情 |
| 公告 | 东方财富 | 研报/公告/财报类 |
| ETF | ETF connector | ETF 轮动与映射 |

## 调用链

推荐调用链：

```text
route -> service -> connector -> normalizer
```

禁止在页面或 route 中散落多个数据源判断。后续需要备用源时，应集中在 service 层实现。

## 数据源切换要求

- 必须更新接口映射文档。
- 必须更新 `source` 返回值。
- 必须跑实时源检查脚本。
- 必须确认空数据不会显示 mock。
- 必须给出回滚方式。

## 失败处理

外部源失败时，接口应该明确返回：

```json
{
  "data": [],
  "count": 0,
  "source": "kpl",
  "data_status": "unavailable",
  "mock": false,
  "message": "KPL 数据源不可用"
}
```
