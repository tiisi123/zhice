# 用户与商业化风险清单

更新时间：2026-04-27  
角色：User Commerce / 用户与商业化

## 结论

当前用户与商业化链路适合小范围内测，不建议直接公开商业化上线。研究池、个人看板具备登录隔离基础，可以内测；支付、会员权益、报告归档权限、AI 配额并发控制仍是上线前必须处理项。

最高风险：

- S1：`ZHICE_JWT_SECRET` 未配置时会生成临时 token 密钥，服务重启后全量登录失效；生产必须强校验。
- S1：支付仍是占位链路，未接微信/支付宝真实回调与验签；生产环境已禁止 `/api/payment/order` 创建 mock 二维码订单，不能开放真实收款入口。
- S2：报告归档 `/api/analysis/report-archive` 已要求登录并仅返回官方/当前用户报告，但仍缺少显式公开/私有可见性字段。
- S2：会员权益主要是前端展示 + 部分后端配额，未形成统一服务端权限矩阵，VIP 权益可被普通登录用户访问的边界不清晰。
- S2：SQLite 单机部署只适合单 worker 和轻量内测，支付订单、配额扣减、提醒扫描在并发下有锁和一致性风险。

## 风险等级说明

| 等级 | 含义 | 上线处理 |
| --- | --- | --- |
| S1 | 登录、支付、权限、隐私数据可能不可用或越权 | 公开上线前必须修复或关闭入口 |
| S2 | 核心能力可用但边界不足，可能影响付费体验或数据一致性 | 只允许内测，需明确人工兜底 |
| S3 | 单页面、状态展示、文案或局部体验问题 | 可灰度，需排期修复 |
| S4 | 非核心文案、样式、说明问题 | 可上线后修复 |

## P0/P1/P2 上线风险

| 级别 | 风险项 | 当前状态 | 上线拦截 |
| --- | --- | --- | --- |
| P0 | 在线支付 | 支付订单和二维码仍是 mock/占位；生产已禁止 `/api/payment/order`，仅允许邀请码 | 真实支付接入、回调验签、幂等对账完成前，必须关闭在线支付入口 |
| P0 | 生产密钥 | `ZHICE_JWT_SECRET` 缺失会生成临时密钥，重启后 token 全失效 | 生产必须配置强随机 `ZHICE_JWT_SECRET`，并由部署门禁确认 |
| P0 | 管理员初始密码 | 未配 `ZHICE_ADMIN_PASSWORD` 时首次启动随机密码写日志 | 生产必须配置强密码，日志不得外泄，建议关闭公开管理入口 |
| P0 | 报告越权 | 归档列表已要求登录并过滤官方/当前用户报告，但缺少显式可见性字段 | 公开上线前需确认官方报告 author_id 规则，后续补 `visibility` |
| P1 | 会员权益 | 会员页展示完整权益，但后端只覆盖部分配额/权限 | 未建立后端权益矩阵前，高级权益只能内测宣传 |
| P1 | AI 配额 | `consume_quota` 覆盖 AI 对话/复盘/回测，仍需逐项核对所有高成本接口 | 高成本接口漏配额时必须关闭入口 |
| P1 | 推荐接口耗时 | `/recommend/strategies` 对 KPL 使用 3 秒超时兜底；AI 解读使用 6 秒超时兜底 | 推荐列表可内测；AI 解读不作为核心 SLA |
| P1 | SQLite 单机 | 用户、订单、配额、归档、研究池、看板均在 SQLite | 生产商业化只允许单 worker；高并发或真实支付前需迁移/补强 |
| P2 | 研究池提醒 | 按 `user_id` 隔离；KPL 失败时返回空提醒，状态标识不足 | 可内测，需补 `source/data_status/mock` 契约 |

## 公开上线闸门

上线前必须完成：

1. 配置并验证 `ZHICE_JWT_SECRET`、`ZHICE_ADMIN_PASSWORD`、`DEBUG=false`、生产 `CORS_ORIGINS`。
2. 关闭真实支付入口，只保留邀请码内测；任何在线支付按钮不得引导用户实际付款。
3. 完善报告归档权限：当前已要求登录并过滤官方/当前用户报告，下一步需增加公开/私有可见性字段。
4. 建立会员权益矩阵：前端展示、后端 `require_vip`、`consume_quota` 覆盖范围一致。
5. 梳理所有 AI 成本接口：未登录必须 401，超配额必须 429，失败不扣或可追踪补偿。
6. SQLite 生产仅单 worker，并建立数据库备份、恢复和锁表应急预案。

## 可内测范围

可在邀请码和白名单用户内测：

- 登录/注册、`AuthGuard` 登录拦截。
- 研究池 CRUD 与异动提醒。
- 我的看板保存/加载。
- 会员邀请码兑换。
- AI 对话和 AI 复盘配额。
- 推荐策略列表。

仅可关闭入口或管理员验证：

- 在线支付下单二维码。
- 报告归档全局列表。
- 会员高级权益承诺。
- 管理员邀请码生成页。
- 推荐 AI 解读的公开高频入口。

## 回滚预案

- 登录异常：回滚后端版本，恢复上一版 `ZHICE_JWT_SECRET`，提示用户重新登录。
- 支付误开放：立即关闭 `/membership` 在线支付入口和 `/api/payment/order` 入口，保留订单表用于人工核对。
- 报告越权：关闭 `/my-workspace?tab=archive` 和 `/api/analysis/report-archive`，导出访问日志，核对 author_id 与可见性规则后再恢复。
- 配额异常：临时下调 AI 入口频率或关闭高成本入口，核对 `user_quota` 与 LLM 调用日志。
- SQLite 锁定：切单 worker，停止调度器扫描，备份 `data/zhice.db` 后恢复服务。
