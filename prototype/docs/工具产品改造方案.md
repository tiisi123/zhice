# 工具板块产品改造方案

> 生成日期：2026-04-26  
> 范围：工具大板块、PRD 工具/策略/用户体系相关需求、现有 Web 功能模块。  
> 目标：将当前分散的工具菜单改造成面向专业投资经理、基础投资者、短线交易者的投研执行中枢。

---

## 1. 访谈结论

| 问题 | 结论 |
|---|---|
| 工具板块定位 | 三类用户都要，但根据用户风格切换默认布局 |
| 一级入口 | 标的研究 / 研究池 / 策略工坊 / 我的工作台 / 会员 |
| 个股分析 | 综合个股卡，按用户风格切换重点 |
| 策略功能 | 策略回测、可视化构建器、高级策略、策略推荐、策略实验室统一放进“策略工坊” |
| 研究池 | 自选列表 + CRM 式研究管线 + 交易观察池三者结合，支持分组模板 |
| 自定义看板 | 从“空白搭组件”改成“角色模板优先” |
| 用户命名 | 不使用“小白”，改为“基础投资者” |
| 报告存档 | 升级为“研究档案库” |
| 会员中心 | 按“用户任务价值”重写，不再按功能次数罗列 |
| 会员分层 | 基础版 / 标准版 / 专业版，全部按收费产品思路设计 |

---

## 2. 产品定位

当前工具板块包括：

```text
个股分析
研究池
产业链图谱
策略回测
可视化构建器
高级策略
策略推荐
策略实验室
自定义看板
报告存档
会员中心
```

这些功能本身都有价值，但现在更像“功能工具箱”，缺少明确工作流。用户进入后需要自己判断先用哪个、怎么串起来。

工具板块应升级为：

```text
投研执行中枢：把想法变成研究结论，把研究结论变成可验证策略，把策略和观察标的沉淀成个人工作流。
```

核心主线：

```text
发现标的 -> 加入研究池 -> 验证策略 -> 沉淀报告 -> 形成个人工作台 -> 会员持续使用
```

## 3. 目标用户

### 3.1 专业投资经理

典型路径：

```text
找标的 -> 深度研究 -> 横向比较 -> 策略验证 -> 组合跟踪 -> 报告归档
```

核心诉求：

- 提高研究效率
- 快速判断标的质量
- 产业链和题材逻辑验证
- 策略逻辑回测
- 研究过程可沉淀
- 看板能服务日常工作

### 3.2 基础投资者

典型路径：

```text
输入股票 -> 看懂结论 -> 加入观察 -> 获得提醒 -> 学习策略
```

核心诉求：

- 快速看懂一只股票
- 明确风险点
- 不被复杂指标淹没
- 有 AI 解释专业术语
- 可以逐步学习策略和研究流程

### 3.3 短线交易者

典型路径：

```text
盘中发现标的 -> 看题材/强度/联动 -> 加观察池 -> 验证打板策略 -> 复盘沉淀
```

核心诉求：

- 快速看题材和涨停原因
- 同题材联动
- 研究池实时提醒
- 打板/接力/反包策略验证
- 报告回看和失败案例沉淀

## 4. 信息架构重构

建议将工具一级入口收敛为：

```text
工具
  标的研究
  研究池
  策略工坊
  我的工作台
  会员
```

### 4.1 原模块归属

| 原模块 | 新入口 | 改造方向 |
|---|---|---|
| 个股分析 | 标的研究 | 升级为综合个股研究卡 |
| 产业链图谱 | 标的研究 | 升级为产业链机会地图 |
| 研究池 | 研究池 | 升级为研究管线 + 异动提醒 |
| 策略推荐 | 策略工坊 | 策略入口前置，解决“我该测什么” |
| 策略回测 | 策略工坊 | 从指标堆叠升级为策略体检报告 |
| 可视化构建器 | 策略工坊 | 从 DSL 工具升级为策略搭积木 |
| 高级策略 | 策略工坊 | 参数优化、模拟交易作为高级能力 |
| 策略实验室 | 策略工坊 | 策略对比、自定义规则、风格学习 |
| 自定义看板 | 我的工作台 | 角色模板优先，而不是空白搭建 |
| 报告存档 | 我的工作台 | 升级为研究档案库 |
| 会员中心 | 会员 | 按用户任务价值包装权益 |

## 5. 工具首页

### 5.1 页面目标

工具首页建议命名：

```text
投研工具台
```

目标不是展示所有工具按钮，而是告诉用户今天应该处理什么。

### 5.2 首页信息流

```text
顶部：今日工具台摘要
左侧：我的研究池异动
中间：正在验证的策略
右侧：AI 下一步建议
下方：最近报告 / 最近查看标的 / 常用工具入口
```

### 5.3 示例文案

```text
今日 3 只研究池标的触发提醒
2 个策略回测结果待查看
半导体产业链景气上行，建议补充研究
昨日 AI 复盘已归档，可生成周总结
```

### 5.4 推荐图示

- 今日待办时间线
- 研究池异动卡片
- 策略验证进度条
- 最近报告时间线
- 常用工具快捷入口

## 6. 标的研究

标的研究合并：

```text
个股分析 + 产业链图谱
```

### 6.1 页面目标

回答：

```text
这个标的值不值得继续研究？
它的短线逻辑、基本面逻辑、产业链位置和风险分别是什么？
```

### 6.2 综合个股卡

个股页改造成“综合个股研究卡”，按用户风格切换重点。

#### 基础投资者视角

优先展示：

- 一句话结论
- 风险等级
- 当前是否值得继续研究
- AI 简明解释
- 加入研究池

表达方式：

```text
看懂这只股票：它为什么涨？风险在哪里？适合继续观察吗？
```

#### 专业投资经理视角

优先展示：

- 公司质量
- 估值位置
- 财报变化
- 产业链位置
- 预期差
- 研究报告

表达方式：

```text
这只股票是否具备中长期配置价值？
```

#### 短线交易者视角

优先展示：

- 涨停原因
- 连板高度
- 题材归属
- 同题材联动
- 资金画像
- K 线形态匹配
- 明日风险

表达方式：

```text
这只票是否是主线核心？明日还能不能接？
```

### 6.3 页面结构

```text
顶部：一句话结论 + 风险灯 + AI参考动作
中部：短线逻辑 / 基本面 / 题材 / 资金 / 风险
右侧：AI 研究摘要 + 加入研究池
底部：产业链位置 + 历史相似案例 + 报告生成
```

### 6.4 推荐图示

- 个股质量雷达
- 题材归属图
- 产业链位置图
- 资金流向条
- 风险红绿灯
- 历史相似形态曲线
- 估值分位带

### 6.5 产业链机会地图

现有产业链图谱应从“关系图”升级为“机会地图”。

核心问题：

- 哪个环节最景气？
- 哪个环节利润最受益？
- 哪个环节估值还没反映？
- 哪些公司是核心受益？
- 上游涨价对下游是利好还是利空？

信息流：

```text
上游 -> 中游 -> 下游 -> 受益公司 -> 传导时滞 -> 投资机会
```

推荐图示：

- 产业链传导图
- 上中下游景气条
- 利润分配漏斗图
- 受益公司气泡图
- 催化事件时间线

## 7. 研究池

### 7.1 页面目标

研究池不只是自选股列表，而应成为用户的研究管线。

核心问题：

```text
我关注的标的现在处于什么研究状态？
哪些标的触发了新变化？
哪些应该推进研究、加入重点、剔除或转入持仓？
```

### 7.2 研究管线

建议默认状态：

```text
观察 -> 验证 -> 重点跟踪 -> 已持有 -> 剔除
```

每只标的卡片展示：

- 当前状态
- 加入理由
- 触发条件
- 失效条件
- 最近异动
- AI 摘要
- 相关报告

### 7.3 分组模板

#### 短线交易模板

```text
龙头池
补涨池
反包池
风险池
```

#### 成长经理模板

```text
景气上行
拐点验证
核心跟踪
估值等待
```

#### 价值研究模板

```text
低估观察
财报验证
高股息
剔除观察
```

#### 基础投资者模板

```text
想了解
正在观察
重点关注
风险提醒
```

### 7.4 页面结构

```text
顶部：今日研究池异动
中部：研究管线看板
右侧：提醒历史 / AI 总结
底部：全部明细
```

### 7.5 推荐图示

- 研究管线看板
- 异动提醒时间线
- 标的状态卡
- 分组风险热力
- AI 今日摘要

## 8. 策略工坊

策略工坊统一承接：

```text
策略推荐
策略构建器
策略回测
高级策略
策略实验室
```

### 8.1 页面目标

回答：

```text
我的交易/投资想法有没有历史胜率？
当前市场环境适不适合这个策略？
策略参数是否稳健？
是否值得模拟运行？
```

### 8.2 信息流

```text
推荐策略 -> 搭建策略 -> 回测验证 -> 参数优化 -> 模拟运行 -> 策略归档
```

### 8.3 子板块

| 子板块 | 作用 |
|---|---|
| 策略推荐 | 根据用户风格和市场环境推荐策略 |
| 策略构建器 | 条件卡片搭建策略 |
| 策略回测 | 验证收益、回撤、胜率、适用行情 |
| 参数优化 | 找到稳健参数区间 |
| 模拟组合 | 模拟运行策略 |
| 策略实验室 | 策略对比、自定义规则、多风格学习 |

### 8.4 策略推荐

不要只展示 DSL，要翻译成人话。

推荐卡片应包含：

- 推荐策略
- 适用行情
- 风险等级
- 为什么适合你
- 为什么适合当前市场
- 回测摘要
- 一键回测
- 一键加入策略观察

### 8.5 策略构建器

从“开发者 DSL 工具”升级为“策略搭积木”。

步骤：

```text
第一步：选什么
第二步：什么时候买
第三步：什么时候卖
第四步：买多少
第五步：什么市场环境才启用
```

UI 控件：

- 条件卡片
- 滑块
- 开关
- 策略流程图
- 实时策略摘要
- 一键回测

DSL 放到“高级预览”，默认隐藏。

### 8.6 策略回测

从指标展示升级为“策略体检报告”。

顶部直接给：

```text
策略评级：可观察 / 可小仓试用 / 不建议
主要问题：回撤过深 / 样本不足 / 过拟合 / 只适合回暖行情
```

报告结构：

```text
策略结论
适用市场
收益曲线
回撤区间
胜率/盈亏比
失效场景
参数建议
```

推荐图示：

- 净值曲线
- 回撤水下图
- 月度收益热力图
- 盈亏分布图
- 参数敏感性热力图
- 策略适用环境雷达

### 8.7 参数优化

不只展示 Best5/Worst3 表格，应输出：

- 参数热力图
- 稳健区间
- 过拟合提示
- 推荐参数区间
- 极端行情下表现

### 8.8 策略实验室

作为策略工坊高级 Tab：

- 策略对比
- 自定义打板规则
- 多风格组合
- 风格学习
- 模拟账户

## 9. 我的工作台

我的工作台合并：

```text
自定义看板 + 报告存档
```

### 9.1 页面目标

让用户沉淀自己的投研体系，而不是每次重新开始。

核心问题：

```text
我每天要看什么？
我的研究、复盘、策略和报告沉淀在哪里？
```

### 9.2 角色模板优先

自定义看板从“空白搭组件”改成“角色模板优先”。

推荐模板：

| 模板 | 适用用户 | 默认组件 |
|---|---|---|
| 短线交易看板 | 游资/短线用户 | 研究池异动、连板跟踪、炸板风险、策略回测、复盘报告 |
| 成长投资看板 | 成长经理 | 景气热力、拐点预警、产业链机会、成长候选池、行业报告 |
| 价值研究看板 | 价值研究员 | 持仓健康、估值分位、财报追踪、预期修正、个股报告 |
| 基础投资看板 | 基础投资者 | 个股诊断、风险提醒、研究池、AI解释、学习型策略 |

### 9.3 研究档案库

报告存档升级为“研究档案库”。

报告类型：

```text
复盘报告
个股报告
行业报告
策略报告
投委会备忘录
交易/研究决策记录
```

页面结构：

```text
左侧：时间线 / 标签筛选
中间：报告列表
右侧：报告详情 + AI 追问
顶部：主题聚合和搜索
```

AI 应支持：

- 周总结
- 主线追踪
- 标的反复出现统计
- 策略有效性回看
- 研究判断验证或推翻

## 10. 会员

### 10.1 会员定位

会员中心按“用户任务价值”重写，不再主推功能次数。

产品不强调免费版，采用全收费产品逻辑：

```text
基础版：看懂基础结论
标准版：完成完整研究流程
专业版：策略验证 + 个性化工作台 + 深度报告沉淀
```

### 10.2 权益表达

| 等级 | 用户任务价值 | 核心卖点 |
|---|---|---|
| 基础版 | 看懂基础结论 | 个股结论、风险提示、基础研究池、基础报告查看 |
| 标准版 | 完成完整研究流程 | 标的研究、产业链图谱、研究池提醒、AI 研究摘要、报告归档 |
| 专业版 | 策略验证 + 个性化工作台 + 深度报告沉淀 | 策略工坊、参数优化、专业看板、投委会备忘录、深度报告库 |

### 10.3 页面表达

不要只写：

```text
每日 10 次 AI
每日 20 次回测
```

而要写：

```text
基础版：我能快速看懂一个标的
标准版：我能完成一次完整投研
专业版：我能验证策略并沉淀自己的投研体系
```

次数、额度可以作为次级说明，不作为主卖点。

## 11. UI / UE 原则

### 11.1 任务先行

工具页不应问“你要用哪个功能”，而应帮助用户完成任务：

```text
查一个标的
跟踪一组股票
验证一个策略
整理一份报告
搭建一个工作台
```

### 11.2 图示优先

减少大表格，优先使用：

- 研究管线
- 产业链图谱
- 策略流程图
- 净值曲线
- 回撤水下图
- 参数热力图
- 报告时间线
- 风格模板卡

### 11.3 分层信息

基础投资者：

```text
先看结论，再展开指标。
```

专业投资经理：

```text
先看结论和证据，再看明细数据。
```

短线交易者：

```text
先看异动、题材、风险，再看历史验证。
```

### 11.4 避免工具孤岛

每个工具之间要有明确跳转：

```text
个股分析 -> 加入研究池
研究池 -> 生成个股报告
策略推荐 -> 去回测
回测结果 -> 加入策略观察
报告存档 -> AI 回看
看板 -> 固定常用组件
```

### 11.5 AI 角色

AI 不只是聊天入口，而是工具中的研究助理。

固定输出：

```text
核心结论
关键证据
反向风险
下一步动作
跟踪指标
```

## 14. 第一刀建议

推荐第一刀：

```text
工具导航结构 + 投研工具台首页
```

原因：

- 不破坏现有功能
- 立刻降低菜单复杂度
- 能把工具从“功能列表”变成“工作流入口”
- 后续标的研究、研究池、策略工坊都能自然承接

第二刀：

```text
策略工坊整合
```

原因：

- 当前策略相关入口最分散
- 也是专业版付费价值最强的模块
- 能把“策略推荐 -> 构建 -> 回测 -> 优化 -> 模拟”串成完整闭环

第三刀：

```text
研究池管线化
```

原因：

- 研究池是用户留存核心
- 也是个股研究、盘中提醒、报告归档的中间枢纽

## 16. 页面内横向子模块导航

### 16.1 设计原则

工具板块建议采用：

```text
左侧一级导航：标的研究 / 研究池 / 策略工坊 / 我的工作台 / 会员
页面内横向导航：当前工具内的任务步骤
```

工具板块横向导航的核心不是“再列一次功能”，而是让用户明确当前任务进展。

统一原则：

- 横向导航要按任务流程排序。
- 默认 Tab 必须是最容易理解的结论页。
- 高级功能下沉，不作为默认入口。
- 基础投资者看到结论和解释，专业用户可以展开明细。
- 短线交易者看到异动和风险，专业经理看到研究链路。
- Tab 切换保持当前股票、策略、研究池分组、筛选条件。

### 16.2 投研工具台横向导航

页面目标：让用户知道今天该处理哪些投研任务。

横向导航：

```text
今日待办 | 研究池异动 | 策略待验证 | 最近报告 | 常用工具
```

| Tab | 核心问题 | 推荐展示 |
|---|---|---|
| 今日待办 | 今天最该处理什么？ | 待办卡、AI 下一步建议 |
| 研究池异动 | 哪些标的触发变化？ | 异动卡片、提醒时间线 |
| 策略待验证 | 哪些策略需要回看？ | 回测结果、策略状态 |
| 最近报告 | 最近沉淀了什么？ | 报告时间线、AI 周总结 |
| 常用工具 | 快速去哪？ | 标的研究、研究池、策略工坊快捷入口 |

专业建议：工具首页不要默认展示一堆入口按钮，而要默认打开“今日待办”，让产品像助理而不是工具箱。

### 16.3 标的研究横向导航

页面目标：让用户快速判断一个标的是否值得继续研究。

横向导航：

```text
综合诊断 | 短线逻辑 | 基本面 | 产业链 | 风险证据 | 报告生成
```

| Tab | 核心问题 | 推荐展示 |
|---|---|---|
| 综合诊断 | 这只标的值得继续研究吗？ | 一句话结论、风险灯、AI 参考动作 |
| 短线逻辑 | 是否处在题材/资金主线？ | 涨停解码、同题材联动、形态匹配 |
| 基本面 | 公司质量是否过关？ | 质量雷达、财报趋势、估值分位 |
| 产业链 | 它处于哪个环节？ | 产业链位置、受益逻辑、传导时滞 |
| 风险证据 | 有哪些反向证据？ | 财报异常、估值偏高、资金背离、公告风险 |
| 报告生成 | 如何沉淀研究？ | AI 个股报告、加入研究池、归档 |

专业建议：默认 Tab 根据用户风格切换。基础投资者默认“综合诊断”，短线交易者默认“短线逻辑”，专业投资经理默认“基本面”。

### 16.4 研究池横向导航

页面目标：从自选列表升级为研究管线。

横向导航：

```text
管线视图 | 异动提醒 | 分组模板 | 跟踪笔记 | 明细列表
```

| Tab | 核心问题 | 推荐展示 |
|---|---|---|
| 管线视图 | 每只标的处于什么研究状态？ | 观察/验证/重点/持有/剔除看板 |
| 异动提醒 | 哪些标的有变化？ | 当前触发、近 7 日命中、风险标签 |
| 分组模板 | 如何快速建立研究池？ | 短线、成长、价值、基础投资模板 |
| 跟踪笔记 | 研究结论如何沉淀？ | 标的笔记、触发条件、失效条件 |
| 明细列表 | 查看全部数据 | 表格、批量编辑、导出 |

专业建议：研究池默认打开“管线视图”，表格下沉到“明细列表”。这会明显降低工具感，增强工作流感。

### 16.5 策略工坊横向导航

页面目标：把策略想法变成可验证、可优化、可归档的策略资产。

横向导航：

```text
推荐策略 | 策略搭建 | 回测体检 | 参数优化 | 模拟组合 | 实验室
```

| Tab | 核心问题 | 推荐展示 |
|---|---|---|
| 推荐策略 | 当前适合测什么？ | 风格匹配、市场适配、风险等级 |
| 策略搭建 | 如何表达我的想法？ | 条件卡片、流程图、自然语言生成 |
| 回测体检 | 策略能不能用？ | 策略评级、净值曲线、回撤水下图 |
| 参数优化 | 参数是否稳健？ | 参数热力图、稳健区间、过拟合提示 |
| 模拟组合 | 能否模拟运行？ | 模拟账户、持仓、收益曲线 |
| 实验室 | 高级玩法 | 策略对比、自定义规则、风格学习 |

专业建议：策略工坊默认打开“推荐策略”，因为多数用户不是先写策略，而是先需要知道“现在该验证什么策略”。

### 16.6 我的工作台横向导航

页面目标：沉淀用户自己的投研系统。

横向导航：

```text
模板看板 | 研究档案 | 投委会备忘录 | 周总结 | 设置
```

| Tab | 核心问题 | 推荐展示 |
|---|---|---|
| 模板看板 | 我的默认工作台长什么样？ | 短线交易、成长投资、价值研究、基础投资模板 |
| 研究档案 | 研究成果在哪里？ | 复盘、个股、行业、策略报告 |
| 投委会备忘录 | 重要决策如何沉淀？ | 决策摘要、证据、风险、动作 |
| 周总结 | 最近一周有什么变化？ | AI 周总结、主线追踪、策略回看 |
| 设置 | 工作台如何个性化？ | 默认模板、组件排序、通知 |

专业建议：自定义看板不要默认空白。用户第一次进入时先选择角色模板，再允许细调。

### 16.7 会员横向导航

页面目标：让用户理解不同版本能完成什么任务。

横向导航：

```text
任务价值 | 基础版 | 标准版 | 专业版 | 权益对比
```

| Tab | 核心问题 | 推荐展示 |
|---|---|---|
| 任务价值 | 为什么要付费？ | 看懂标的、完成研究、验证策略三段价值 |
| 基础版 | 能看懂什么？ | 个股结论、风险提示、基础研究池 |
| 标准版 | 能完成什么研究？ | 标的研究、产业链图谱、报告归档 |
| 专业版 | 能建立什么体系？ | 策略工坊、专业看板、深度档案库 |
| 权益对比 | 具体差异是什么？ | 权益矩阵、额度说明 |

专业建议：会员中心默认打开“任务价值”，不要默认打开价格表或权益表。先让用户理解“我买的是工作流能力”。
