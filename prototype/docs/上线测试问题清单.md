# 智策 Web 上线测试问题清单

## 测试范围

- **前端页面**：`App.tsx` 中注册的全部页面路由，以及 `AppLayout` 菜单入口。
- **后端模块**：`apps/api/main.py` 注册的全部 FastAPI 路由模块。
- **测试视角**：以真实投研/量化用户访问路径检查可用性、构建门禁、接口稳定性、页面入口一致性、上线风险。

## 第一轮测试记录

### 测试动作

- **前端生产构建**：执行 `npm run build`。
- **后端语法检查**：执行 `python -m py_compile apps/api/main.py` 以及 `apps/api/routes/*.py`。
- **路由/菜单静态巡检**：检查 `App.tsx` 与 `AppLayout.tsx` 注册页面和菜单入口。
- **API 代理检查**：检查 Vite `/api` 与 `/api/ws` 代理配置。

### 第一轮修复记录

- **R1-002**：将 `AuthGuard` 中的 `clearAuth` 动态导入改为静态导入，消除无效动态导入构建警告。
- **R1-001**：在 Vite 配置中增加 `manualChunks`，拆出 `react`、`antd`、`charts` vendor chunk，显著缩小业务入口 chunk。
- **R1-004**：Windows 环境改用 PowerShell 枚举后端路由文件进行 `py_compile` 校验。
- **R1-005**：复查 `useAnomalyAlerts`，确认未登录不发请求，异常静默，不作为阻断项。

### 第一轮复测结果

- **前端构建**：通过。
- **后端语法检查**：通过。
- **剩余风险**：`antd`、`echarts` vendor chunk 仍超过 500kB，需依赖浏览器缓存/CDN 或后续按组件级导入继续优化。

## 最终上线结论

### 当前状态

- **功能 smoke**：通过。
- **生产构建**：通过。
- **后端语法**：通过。
- **测试文档**：已生成并记录三轮问题、修复和剩余风险。

### 上线前必须处理

1. **重启/清理旧后端进程**：确保生产或本地默认 `8000` 启动的是当前代码版本，否则 `/api/news/*` 会 404；本地可先使用 `scripts/start_verified_dev.ps1` 固定验证 `8010/5174`。
2. **确定 lint 门禁策略**：当前 `npm run lint` 有大量历史错误；若 CI 强制 lint，必须先分批修复或调整上线门禁为 `build + smoke + py_compile`。
3. **配置生产密钥**：启动日志提示 `ZHICE_JWT_SECRET` 未设置，生产必须配置固定强密钥，否则重启后 token 全部失效。
4. **静态资源缓存策略**：`antd` / `echarts` vendor 较大，建议上线时启用 gzip/br、强缓存和 CDN。

### 建议结论

在完成以上 4 项上线前动作后，可以进入预发布/灰度；当前不建议直接把正在监听 `8000` 的旧服务作为上线版本。

### 当前推荐验证命令

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start_verified_dev.ps1 -ApiPort 8010 -WebPort 5174
```
